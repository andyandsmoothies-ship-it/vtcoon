# AGENTS CONSTITUTION (PROJECT HARNESS)

> Precedence: This project harness specializes Global AG OS Rules. Project rules strictly override global rules in case of conflict.
> Language Policy: All settings, instructions, and harness files must be in concise English. User-facing reports (`docs/reports/**`) and game artifacts must be in Vietnamese.

## 1. MANDATORY MECHANICAL GATES
Every ticket (outside Fast-Track) must pass 100% of automated gates before handoff:
1. **Plan Audit & Signoff**: `node scripts/audit_plan.mjs <plan_path> [--auto-sign]`
2. **Scope Confinement**: `node scripts/check_scope.mjs [plan_path]`
3. **Fast Pre-Filter (Type, LOC, Linters, Assert Density)**: `npm run prefilter -- <files>`
4. **Live Socket Port 0 & Mutation**: `npm run sentinel -- --ticket <id> --test <test_path>`
5. **Comprehensive Evidence Audit**: `node scripts/check_evidence.mjs <ticket>`
*(All toolchain scripts adhere to the Facade Re-export Pattern: root `scripts/*.mjs` are lean facades <= 200 LOC; specialized logic lives in `scripts/report/`, `scripts/slop_linter/`, `scripts/boundary_linter/`, `scripts/visual_capture/`, `scripts/plan_audit/`, `scripts/sentinel/`, `scripts/evidence_audit/`).*

## 2. UNIVERSAL IRON LAWS (NEGATIVE CONSTRAINTS - VIOLATION = EXIT 1)
- **Zero Dirty Casts**: FORBIDDEN `as any`, `as unknown as T`, `@ts-ignore` across `src/**` and `tests/**`.
- **Anti-TIDD**: FORBIDDEN test-only exports, props, methods (`ForTesting`). All new exports in `src/**` must have production consumers outside `tests/**`.
- **Seam Discipline**: Interface is the test boundary. FORBIDDEN monkey-patching frameworks (`spyOn(React)`, `__CLIENT_INTERNALS_*`, `Object.prototype`).
- **LOC Ceilings**: Tier 1 (Domain/FSM/Server) <= 400 LOC; Tier 2 (UI/3D/Views) <= 500 LOC; Tier 3 (Static Config) <= 800 LOC; Living Tests <= 600 LOC. Measure via `npm run check:loc`. Code-golfing banned.
- **Toolchain Facade Invariant**: Root entrypoints in `scripts/*.mjs` MUST remain thin orchestrator facades (<= 200 LOC). Specialized AST rules, extractors, and logic live in corresponding script subdirectories.
- **Assertion Density**: 1-4 asserts (`expect`) per atomic test. FORBIDDEN loops (`for`, `forEach`) in `it()`.
- **Fast & Deterministic Testing**: Use seeded PRNG, dynamic socket port 0, fake timers. FORBIDDEN unseeded `Math.random()` and arbitrary sleeps (>= 3000ms).
- **Non-Interactive CLI Guard**: FORBIDDEN naked `npx <pkg>` without `--yes` in subshells. FORBIDDEN inline multiline PowerShell in `-e "..."`.
- **Teardown & Cleanup Integrity Invariant**: Tests and harness runners MUST fail explicitly (Exit 3 / Teardown Error) if teardown/cleanup hooks fail (unclosed sockets, unfinalized streams, zombie processes), never masking resource leaks as passing tests (exit 0).
- **Bounded CLI Watchdog Invariant**: CLI scripts and toolchain runners MUST unref secondary timers and enforce a bounded exit grace (<= 3s) with process group termination, preventing dangling sockets/timers from stalling agent sessions.
- **Client/Server Boundary**: FORBIDDEN importing Node runtime built-ins (`node:*`, ws) into client bundles. Sockets must use dynamic `port: 0`.
- **Pure-Move Quarantine**: Refactors must preserve 100% behavior. No semantic changes, no silent error swallowing (`try...catch`).
- **Poka-Yoke Domain Affordance**: UI enabled/disabled states and displayed costs MUST derive directly from Domain Validators (`canDo`, `evaluation`), never recalculated independently in presentation layers.
- **Wiring Parity Invariant (Anti-Tautological & Call-Site Wiring)**: FORBIDDEN pure calculation/helper files (`*_helpers.ts`, `*_calc.ts`) tested solely in isolation. Every helper MUST have at least one integration contract test proving its target consumer invokes it and reacts to its output. In Chaos Sentinel, at least one AST mutation probe MUST target the consumer call-site.
- **Knowledge Fold Invariant (SSOT Matrix, Not Changelog)**: Tickets modifying domain rules, economic models, FSM phase transitions, network protocols, or UI affordances MUST update `docs/FEATURE_MAP.md` before Station 3 sign-off. `FEATURE_MAP.md` is an authoritative architecture & rules matrix (SSOT, <= 30 KB), NOT a historical changelog. Historical plans in `.agents/plans/` represent past deltas and MUST NOT be used to deduce current truth.
- **Gotchas Invariant Density Invariant**: Pillar gotchas (`docs/domain/gotchas/*.md`) are strictly architectural invariant rulebooks (<= 15 KB, 3D kinematics <= 20 KB), NOT narrative post-mortem logs.
- **Zero-Boilerplate Audit Invariant**: FORBIDDEN submitting Station 3 audit reports or final acceptance reports containing default generator boilerplate placeholders or generic summaries. Enforced mechanically via `check_evidence.mjs`.
- **View-Model Seam Invariant**: FORBIDDEN mixing complex calculation, state transforms, and hardware/DOM/WebGL rendering inside raw UI/rendering components. Extract pure calculation and state mapping into twin testable helper files (`*_visuals.ts` or `*_helpers.ts`). Contract tests MUST verify pure View-Model functions without brittle UI/graphics mocking.
- **Platform Capability DI Invariant**: FORBIDDEN leaf or deep child components directly importing and executing global device sniffers inside rendering loops. Platform capabilities and tiers MUST be injected deterministically via top-level component props or context.
- **Runtime Self-Healing & Ephemeral TTL Invariant**: FORBIDDEN trusting that external event pairs (`down/up`, `start/end`, `open/close`) will complete unconditionally. Ephemeral flags, gesture tracking collections, and modal locks MUST implement an authoritative Dead Man's Switch (TTL 3s–5s) or watchdog with deterministic self-healing recovery actions.
- **Composite Transaction Testing Invariant**: Financial, economic, or balance-processing tickets MUST verify simultaneous bidirectional flows within the same tick (Inflow alongside Outflow) to eliminate Netting Collision blindspots.
- **Zero Semantic Borrowing Invariant**: FORBIDDEN borrowing existing unrelated enum tokens or action types to represent newly introduced domain behaviors. New operations MUST introduce canonical first-class types.
- **LOC Buffer Zone Guard**: When a target file reaches >= 350 LOC (Tier 1 ceiling 400), adding new logic directly into the file is FORBIDDEN. Plans touching files >= 350 LOC MUST declare a `Refactor-First` step prioritizing Deletion-First before decomposing into Deep Modules (<= 250 LOC). FORBIDDEN micro-splintering (< 30 LOC) solely to evade LOC ceilings.
- **Subsystem Facade Invariant**: Primary subsystems MUST expose an authoritative `index.ts` public facade. External consumers MUST import exclusively via facades or path aliases. Deep relative imports crossing >= 3 directory levels (`../../../../`) bypassing facades are prohibited.
- **Zero Circular Dependency Invariant**: Introducing new circular dependency loops (SCCs) across `src/**` is strictly FORBIDDEN. Enforced mechanically via `npm run lint:boundaries` and prefilter.
- **UI Quality Floor Invariant**: All UI styling across `src/client/**` MUST pass the Impeccable Lite quality floor (0 anti-patterns) enforced mechanically via `npm run lint:ui`. (See `ui_ergonomics.md` and skill `impeccable`).
- **Plan Approval Enforcement Invariant**: Modifying production code (`src/**`) before explicit user approval ("đồng ý" / `status: APPROVED`) is strictly FORBIDDEN. Tickets must undergo Station 0.1 Solution Gate, Station 1 Plan, and Station 1.2/1.5 Audits before any file mutation.
- **SpecGuard Oracle & Anti-Overfitting Invariant (arXiv:2610.16870)**: Test Oracles MUST remain independent from production reference code. FORBIDDEN authoring tests that mirror internal private variable names, temporary loops, or specific data structure choices instead of public behavioral specifications. Every contract test suite MUST include at least one Negative/Violation test case proving malformed inputs or illegal transitions are actively rejected.
- **Anti-Cheat Test Integrity Invariant**: FORBIDDEN `implementer` modifying test files (enforced via Hook + Station 1 `testFileSha256` lock). FORBIDDEN contract tests mocking target production modules (`vi.mock`/`jest.mock` on `targetFiles`). Tests MUST verify public observable contracts, NEVER unmounted intermediate element props or private implementation details. Pure calculation tests MUST assert relational covariance across $\ge 2$ inputs ($f(x_1) \neq f(x_2)$).
- **Dropped Requirements & Anti-Phantom Complexity Invariant (Sean Goedecke Rule)**: Declaring **Explicitly Dropped Requirements** (what is deliberately NOT handled, what can be stale, slow, inflexible, or out-of-scope) is MANDATORY in Station 0.1 & Station 1 Plans. Subagents are strictly FORBIDDEN from introducing unrequested concurrency locks (mutexes), unrequested multi-tier caching, redundant double-checking (TOCTOU guards), or speculative wrapper layers to satisfy hypothetical edge cases not demanded by user contracts.
- **Anti-Confident Gaps Invariant (Thoughtworks Rule)**: FORBIDDEN inventing unconfirmed business rules, edge-case fallbacks, or data policies to artificially polish plans. Requirements MUST be tri-partitioned into Confirmed, Assumed, and Unknown. Unmade product decisions (Unknowns) MUST be surfaced and resolved with the user (`ask_question`) before drafting the plan.
- **Unrepresentable Illegal States Invariant (Yaron Minsky & Matt Pocock Rule)**: FORBIDDEN modeling asynchronous lifecycles, UI components, or FSM transitions with collections of independent boolean flags ("boolean soup" - use `useReducer` / Tagged Unions). Multi-state domains and component lifecycles MUST use Discriminated/Tagged Unions (`{ status: 'idle' } | { status: 'loading' } | ...`), eliminating impossible/corrupt state combinations at compile-time with 0-token instant feedback.
- **Algebraic Invariant & Conservation Testing Invariant**: For financial, treasury, resource allocation, or inventory counters, contract test suites MUST assert global algebraic conservation laws ($\sum \text{allocated} + \text{free} = \text{total}$) across state transitions, preventing leakage and netting blindspots that example-based tests miss.
- **Legible State Fixture Invariant (Expect Testing)**: Complex multi-step coordinators and transaction processors MUST output human-legible text traces/snapshots in verification evidence, reducing human review surface area from deep code tracing to visible before/after behavioral diffs.
- **Build the Lever Invariant**: For batch refactors, repetitive schema/type updates crossing $\ge 5$ files, or mass verification, agents MUST author a reusable deterministic script (`scripts/scratch/` or CLI codemod) to execute the transformation rather than attempting error-prone manual edits.
- **Exploratory Rollback Invariant**: When an exploratory hypothesis, trial patch, or spike test fails, agents MUST execute a clean rollback (`git checkout`/`git reset` or remove scratch files) before attempting hypothesis #2. Leaving dead speculative code, commented-out blocks, or temporary workaround scaffolds in the workspace is FORBIDDEN.
- **Sequential Multi-Finding Remediation Protocol (Anti-Shotgun Editing)**: When resolving multiple findings from Plan Audits, Adversarial Challenges, Chaos Sentinel failures, or Station 3.2 Code Reviews, agents are STRICTLY FORBIDDEN from performing multi-file shotgun edits across unrelated issues in a single unverified diff. Remediation MUST proceed sequentially, one finding at a time: (1) Author 1 discrete boundary test asserting finding #1 (RED); (2) Implement minimal defensive fix (GREEN); (3) Confirm local test passes before moving to finding #2; (4) Run full regression passes (`npm test`, `npm run prefilter`) only after all discrete findings have passed their individual TDD cycle.
- **Remediation Attempt Budget & Escalation Guard**: Subagents (`implementer`, `re-reviewer`) are constrained to a strict budget of maximum 3 attempts per discrete finding or test failure. If an issue remains unresolved after 3 attempts, subagents MUST NOT enter infinite trial-and-error loops; halt immediately, document physical blockers, and escalate to Human Review (`CHALLENGE_ESCALATED` / `MANUAL_REVIEW_REQUIRED`).
- **Finding Fingerprint & Batching Invariant (Paul Bakaus Invariant)**: Harness linters, static audits, and test reporters MUST fingerprint findings by content snippet/rule/target (never unstable physical line numbers) to prevent false-alarm re-reporting, and MUST batch repetitive occurrences into a single primary item suffixed with `(and N more)` to prevent context window flooding.
- **Main Agent Pre-Delivery 1:1 Self-Audit Gate**: FORBIDDEN Main Agent presenting final delivery reports to the user without physically reading the rendered report file (`view_file`) line-by-line to verify 1:1 against physical disk reality, ensuring zero dangling empty headers, accurate SLOC metrics, and strict relevance of included tables.
- **Turn Status Footer Invariant**: End any turn that reports on multi-step, long-running, or delegated work with a concise 4-line status: `**Goal**`: <target milestone>, `**Done**`: <physically completed this turn>, `**Next**`: <immediate next action>, `**Needs you**`: <decision/input or 'nothing'>.
- **Active Principle Traceability Invariant (`Principles Applied`)**: Every Plan, Adversarial Challenge, QA Handoff, and Implementation Handoff MUST include a concise `Principles Applied` list (`[Principle Name] -> [Specific Choice Changed]`) selected from the Core Principles Index: *(1) View-Model Seam Extraction, (2) Equivalence-Partition Testing, (3) Relational Multi-Point Assertion, (4) Ephemeral TTL / Dead Man's Switch, (5) 100% DTO & Call-Site Wiring, (6) Poka-Yoke Domain Affordance, (7) Spatial AABB / Non-Occlusion, (8) Resource Disposal & Cache Hygiene, (9) Platform DI Isolation, (10) Dropped Requirements & Anti-Phantom Complexity (Sean Goedecke Invariant), (11) Sequential Multi-Finding Remediation, (12) STRIDE Trust Boundary Defense, (13) SpecGuard Oracle & Anti-Overfitting Protocol, (14) Build the Lever, (15) Exploratory Rollback Discipline, (16) Chesterton's Fence (Why Before What), (17) Make Illegal States Unrepresentable, (18) Conservation & Algebraic Invariant Testing, (19) Legible State Fixtures (Expect Testing), (20) Requirement Tri-Partitioning (Thoughtworks Rule), (21) Teardown & Cleanup Integrity, (22) Bounded CLI Watchdog, (23) Finding Fingerprint & Batching (Paul Bakaus Invariant), (24) Downstream Blast Radius Mapping, (25) CRAP Score Risk Coupling (Uncle Bob Invariant)*.

## 3. FULL RIGOR SDLC PIPELINE (COHESIVE BATCHING)
- **Session Resume Gate**: When resuming an interrupted session, taking over a dirty workspace, or recovering from context compaction: activate skill `session-resume` to physically reconcile git status, active ticket station (RED/GREEN/Gate), and regression state before making any modifications.
- **Scope: Express (Fast-Track)**: < 50 LOC, visual/CSS/spacing, copy, minor isolated tweak (0 Schema, 0 FSM, 0 Net). Main Agent executes directly in 1-2 min, 0 subagents, 0 plans, 0 reports. Must pass `npm run prefilter` and unit tests.
- **Scope: Refactor (Structural & Type Refactor)**: Pure compile-time types/interfaces, optional schema fields without runtime mutation, subsystem facade re-exports (`index.ts`), import path rewiring, and `declare module` purges (0 FSM transitions, 0 Economic/Cashflow math changes). Main Agent executes directly:
  - **Exemptions**: FORBIDDEN running Chaos Sentinel (`npm run sentinel`) on pure type/barrel files. Exempt from Station 1.5 Adversarial Gate and separate QA/Implementer subagent handoffs.
  - **Required Gates**: MUST pass `tsc --noEmit` (exit 0), `npm run lint:boundaries` (0 hard violations, 0 new SCCs), `npm run prefilter`, and 100% existing regression unit tests (`npm test`). Lean summary report only.
- **Scope: Feature (Standard Cohesive Slice - 50 to 250 LOC - Behavioral & Economic)**:
  - **Cohesive Batching Invariant**: Tightly coupled domain logic MUST be designed and implemented as ONE cohesive slice. Arbitrary over-slicing into multiple micro-tickets that forces repeating the full 8-station pipeline is FORBIDDEN.
  - **Station 0 (Physical Surface Area Probing & Root-Cause Gate)**:
    - **Surface & Blast Radius Probe**: Run `npm run probe:surface -- <target_files>` (LOC, callers, ambient augmentations) and map downstream blast radius (indirect state/event/network ripple effects) before drafting plan.
    - For unfamiliar code, cross-subsystem regressions, or legacy behaviors: activate skill `codebase-archeology` to trace the physical call-graph (/how) and git history (/why / Chesterton's Fence) before drafting the plan.
    - For non-deterministic visual/runtime glitches: isolate physical culprit via observability hooks (`?debug=3d`, layer toggles, console traces, `window.__vtcoon`) before drafting plan.
    - For gameplay, balance, bankruptcy, or state machine desync bugs: inspect In-Game Flight Recorder dump (`npm run analyze:log <dump.json>`) before drafting plan.
  - **Station 0.1 (Solution Exploration & Dropped Requirements Gate)**:
    - **Requirement Tri-Partitioning (Anti-Confident Gaps)**: Tri-partition context into Confirmed (user-verified), Assumed (technical hypothesis), and Unknown (unmade decisions/edge-cases). Surface Unknowns to user via `ask_question` before drafting Plan.
    - **Contrasting Archetypes**: Formulate 2 contrasting approaches: Option A (KISS / Least New Structure / In-place) vs Option B (Extensible / New structure).
    - **Trade-Off Evaluation**: Answer 3 Trade-Off Questions: What can be slow? What can be stale? What can be inflexible?
    - **Explicitly Dropped Requirements**: Mandate declaring what is deliberately out-of-scope to eliminate hypothetical edge cases and prevent AI over-engineering (Sean Goedecke Invariant).
    - **STRIDE Threat Check (Network, Protocol, State & Economy)**: When touching client-server boundaries, WebSocket deltas (`src/domain/protocol/`, `src/server/network/`, `src/client/network/`), bot scheduling, or transactions, evaluate 6 threats: Spoofing (actor ID forging), Tampering (client-dictated prices/rent), Repudiation (unattributed action logs), Information Disclosure (leaking opponent hidden cards/dice sequence), Denial of Service (action spam/modal cancels stalling turn coordinator), Elevation of Privilege (unauthorized intent execution).
  1. **Station 1 (Draft Lean Plan)**: `.agents/plans/PLAN_[ID].md` (<= 200 lines, 0 code-dump, Core Contract Invariants anchoring numbers/wiring, and an `Explicitly Dropped Requirements` section). For decommissioned modules/shims, apply the **Two-Stage Decoupling Pattern** (Phase 1: rewire production and retain 1-line `export * from` stub to protect living tests; Phase 2: modernize tests and delete stub).
  2. **Station 1.2 & 1.5 (Same-Turn Plan Audit & Adversarial Gate)**: Dispatch `node scripts/audit_plan.mjs <plan> --auto-sign` (enforcing mechanical surface probes: ambient module augmentation, export parity, living test callers) and 1 blind adversarial round (`adversarial-challenger` or `forensic-challenger` -> `.agents/audit/PLAN_CHALLENGE_[TICKET].md`) **in the same turn** whenever touching FSM, State, Economy, UI, Mobile, or 3D. Neutral Blind Dispatch Protocol: FORBIDDEN feeding leading hints; auditor MUST execute physical disk queries (`npm run probe:surface`, `vitest run` on living tests).
  3. **Station 1.8 (Human Gate)**: User approves ("đồng ý").
  4. **Station 2 (RED - Autonomous QA Contract Suite)**: Scaffold empty stubs in `src/**` for new files; `qa-tester` consumes the Plan's Core Invariants + Type/DTO contracts and autonomously authors atomic tests by Equivalence Partition (1 test = 1 distinct branch/facet, covering 100% of exported symbols with 0 redundant bloat, Semantic Behavioral RED).
  5. **Station 2.5 (GREEN - Implementation)**: `implementer` writes minimal code in `src/**`.
  6. **Station 3 (Mechanical Verification & Visual Capture Gate)**: Run `npm run prefilter -- <files>`, `node scripts/check_scope.mjs`, and (for UI/3D tickets) `capture_visual_evidence.mjs` while `src/**` is static (NEVER run alongside `sentinel`).
  7. **Station 3.5 (Same-Turn Chaos Sentinel & Visual Critic Gate)**: Dispatch `npm run sentinel -- --ticket <id> --test <test_path>` (exclusive `src/**` mutation lock) and (if UI/3D screenshots exist) `game-3d-visual-critic` **in the same turn**. For 2D UI features, verify 10 Impeccable Lite anti-patterns via `npm run lint:ui` and apply the 6 Core Design Verbs (skill `impeccable`).
  8. **Station 4 (Evidence Synthesis & Delivery Reports)**: Main Agent deterministically synthesizes station audits (`.agents/audit/SPEC_REVIEW_[ID].md`, `CODE_REVIEW_[ID].md`, `PLAN_CHALLENGE_[ID].md`) and final acceptance report (`docs/reports/improvements/IMP-[ID]-[slug]_report.md`) via `npm run report -- [ID]`. Pass `node scripts/check_evidence.mjs <ticket>`. Perform 1:1 physical disk self-audit before presenting.
- **Scope: Epic (> 250 LOC, multi-subsystem)**:
  - Sliced only at natural architectural boundaries into cohesive feature slices. Roadmaps emit high-level milestones before planning.
