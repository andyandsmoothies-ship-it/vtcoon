# AGENTS CONSTITUTION (PROJECT HARNESS)

> Precedence: This project harness specializes Global AG OS Rules. Project rules strictly override global rules in case of conflict.
> Language Policy: All settings, instructions, and harness files must be in concise English. User-facing reports (`docs/reports/**`) and game artifacts must be in Vietnamese.

## 1. MANDATORY MECHANICAL GATES
Every ticket (outside Fast-Track) must pass 100% of automated gates before handoff:
1. **Plan Audit & Signoff**: `node scripts/audit_plan.mjs <plan_path> [--auto-sign]`
2. **Scope Confinement**: `node scripts/check_scope.mjs [plan_path]`
3. **Fast Pre-Filter (Type, LOC, Linters, Assert Density)**: `npm run prefilter -- <files>`
4. **Live Socket Port 0 & Mutation**: `npm run sentinel -- --ticket <id> --test <test_path>`
5. **Comprehensive Evidence Audit**: `node scripts/check_evidence.mjs <ticket>`
*(All toolchain scripts adhere to the Facade Re-export Pattern: root `scripts/*.mjs` are lean facades <= 200 LOC; specialized logic lives in `scripts/report/`, `scripts/slop_linter/`, `scripts/boundary_linter/`, `scripts/visual_capture/`, `scripts/plan_audit/`, `scripts/sentinel/`, `scripts/evidence_audit/`).*

## 2. IRON LAWS (NEGATIVE CONSTRAINTS - VIOLATION = EXIT 1)
- **Zero Dirty Casts**: FORBIDDEN `as any`, `as unknown as T` across `src/**` and `tests/**`.
- **Anti-TIDD**: FORBIDDEN test-only exports, props, methods (`ForTesting`). All new exports in `src/**` must have production consumers outside `tests/**`.
- **Seam Discipline**: Interface is the test boundary. FORBIDDEN monkey-patching frameworks (`spyOn(React)`, `__CLIENT_INTERNALS_*`, `Object.prototype`).
- **LOC Ceilings**: Tier 1 (Domain/FSM/Server) <= 400 LOC; Tier 2 (UI/3D/Views) <= 500 LOC; Tier 3 (Static Config) <= 800 LOC; Living Tests <= 600 LOC. Measure via `npm run check:loc`. Code-golfing banned.
- **Toolchain Facade Invariant**: Root entrypoints in `scripts/*.mjs` MUST remain thin orchestrator facades (<= 200 LOC). All new script logic, AST rules, or telemetry extractors MUST be implemented in the corresponding subdirectories (`scripts/report/`, `scripts/slop_linter/`, `scripts/visual_capture/`, `scripts/plan_audit/`, `scripts/sentinel/`, `scripts/evidence_audit/`).
- **Assertion Density**: 1-4 asserts (`expect`) per atomic test. FORBIDDEN loops (`for`, `forEach`) in `it()`.
- **Fast & Deterministic Testing**: Use seeded PRNG, zero-delay sockets, fake timers. FORBIDDEN unseeded `Math.random()` and arbitrary sleeps (>= 3000ms).
- **Non-Interactive CLI Guard**: FORBIDDEN naked `npx <pkg>` without `--yes` in subshells. FORBIDDEN inline multiline PowerShell in `-e "..."`.
- **Client/Server Boundary**: FORBIDDEN importing Node runtime built-ins (`node:*`, ws) into client bundles. Sockets must use dynamic `port: 0`.
- **Pure-Move Quarantine**: Refactors must preserve 100% behavior. No semantic changes, no error swallowing (`try...catch`).
- **Poka-Yoke UI Affordance**: Button enabled/disabled states and displayed costs MUST derive directly from Domain Validators (`canDo`, `evaluation`), never recalculated independently.
- **i18n Exhaustiveness**: Every `ActionRejectReason` code must map 100% in `src/domain/i18n/vi.ts` typed `Record<ActionRejectReason, string>`.
- **Core Invariants in Plan & QA Function Parity Protocol**: Lean Plans (Station 1) declare concise Core Contract Invariants (1 per distinct business/spatial/architectural rule; typically 3–6 invariants anchoring numbers, thresholds, and wiring). In Station 2, `qa-tester` autonomously expands these invariants into atomic tests by Equivalence Partition & Branch Parity (100% exported symbol coverage, zero redundant bloat). Scaffold empty stubs before Station 2 for Semantic Behavioral RED.
- **Wiring Parity Invariant (Anti-Tautological & Call-Site Wiring)**: FORBIDDEN pure calculation/helper files (`*_helpers.ts`, `*_detect.ts`, `*_math.ts`) with contract tests that only invoke the helper in isolation without verifying its physical call-site. Every new or modified helper function MUST have at least one integration contract test proving that its target production consumer invokes it and reacts to its output. In Chaos Sentinel, at least one AST mutation probe MUST target the consumer call-site.
- **Knowledge Fold Invariant (SSOT Matrix, Not Changelog)**: Any ticket modifying domain rules, economic models, FSM phase transitions, network protocols, or UI affordances MUST update `docs/FEATURE_MAP.md` before Station 3 sign-off. `FEATURE_MAP.md` is an authoritative architecture & rules matrix (SSOT), NOT a ticket changelog or historical logbook. It MUST NOT exceed 30 KB. Ticket narratives and point-in-time diffs belong strictly in `docs/reports/` and `.agents/plans/`.
- **SSOT Primacy Invariant**: When researching gameplay rules, economic variables, FSM phases, or subsystem boundaries, agents MUST treat `docs/FEATURE_MAP.md` as the authoritative Single Source of Truth. Historical plans in `.agents/plans/` represent past deltas and MUST NOT be used to deduce current truth.
- **Gotchas Invariant Density Invariant**: Pillar gotchas (`docs/domain/gotchas/*.md`) are strictly architectural invariant rulebooks, NOT historical post-mortem logs. Appending narrative ticket stories (`Deceptive Trap: In IMP-xxx...`) is FORBIDDEN. Rules must be concise, quantified statements of negative constraints, mathematical formulas, and coordinates. Enforced mechanically: individual gotcha files must not exceed 15 KB (3D kinematics <= 20 KB).
- **Zero-Boilerplate Audit Invariant**: FORBIDDEN submitting Station 3 audit reports or final acceptance reports containing default generator boilerplate placeholders or generic summaries. Enforced mechanically via `check_evidence.mjs`.
- **Graphics & UI View-Model Seam Invariant**: FORBIDDEN mixing complex visual calculation/transform math, store selectors, and WebGL/DOM rendering inside raw JSX components. Any new or modified 3D/UI feature MUST extract pure calculation and state mapping into a twin pure helper file (`*_visuals.ts` or `*_helpers.ts`). Contract tests in Station 1 MUST verify pure View-Model functions without brittle headless Three.js WebGL mocking. Call-site integration tests MUST use `tests/helpers/r3f_test_harness.ts`.
- **Standardized Graphics Fixture Invariant**: FORBIDDEN creating bespoke local mocks of `@react-three/fiber` or Three.js frame loops across test files. All R3F lifecycle, `useFrame`, and WebGL context simulation MUST use the centralized test seam `tests/helpers/r3f_test_harness.ts`.
- **Device Sniffing Dependency Injection Invariant**: FORBIDDEN leaf or deep 3D/UI child components directly importing and executing global device sniffers (`isMobileHardware`, `isPhoneHardware`, `isIOSPhone`) inside rendering loops or nested subtrees. Platform capabilities and hardware tiers MUST be injected deterministically via top-level Component Props or a centralized Context/store selector. Contract and unit test suites MUST verify mobile vs desktop variants purely via prop/context configuration without monkey-patching globals or using `vi.spyOn` on device detection modules.
- **Main Agent Pre-Delivery 1:1 Self-Audit Gate**: FORBIDDEN Main Agent presenting final delivery reports to the user without physically reading the rendered report file (`view_file`) line-by-line to verify 1:1 against physical disk reality, ensuring zero dangling empty headers, accurate SLOC metrics, and strict relevance of included tables.
- **Runtime Self-Healing & Ephemeral TTL Invariant**: FORBIDDEN trusting that external event pairs (`down/up`, `start/end`, `open/close`) will complete unconditionally. Ephemeral flags (`isRolling`, `isPawnAnimating`), gesture tracking collections (`activePointers`), and modal/subsystem locks MUST implement an authoritative Dead Man's Switch (TTL 3s–5s) or background watchdog that auto-clears stalled state with deterministic self-healing recovery actions.
- **Composite Transaction Testing Invariant**: FORBIDDEN financial, economic, or balance-processing implementation tickets omitting composite integration tests. When modifying event synthesizers or balance delta processors, contract test suites MUST include at least one scenario verifying simultaneous bidirectional cashflows within the same tick (e.g. Inflow alongside Outflow) to eliminate Netting Collision blindspots.
- **Zero Semantic Borrowing Invariant**: FORBIDDEN borrowing existing unrelated enum tokens or action types (`unmortgage`, `tax`) to represent newly introduced economic behaviors. New financial or domain operations MUST introduce canonical first-class types across `ActivityLogType`, `FloatingActionType`, and UI narrative formatters.
- **LOC Buffer Zone Guard**: When a target file reaches >= 350 LOC (Tier 1 ceiling 400), adding new logic directly into the file is FORBIDDEN. Plans touching files >= 350 LOC MUST declare a `Refactor-First` step prioritizing **Deletion-First** (pruning dead code, obsolete fallbacks, unused options) before decomposing into Deep Modules or pure test seams (<= 250 LOC). FORBIDDEN extracting shallow single-function micro-files solely to evade the LOC ceiling.
- **Deep Modules & Seam Discipline (Anti-Micro-Splintering & Middle-Man Ban)**: Pure calculation and view-model test seams (twin files like `*_visuals.ts`) are fully legitimate architectural seams where test suites serve as the valid 2nd consumer. FORBIDDEN micro-splintering logic into trivial files (< 30 LOC) solely to evade LOC ceilings (exempt: pure types, constants, barrel re-exports, UI components). FORBIDDEN creating 1-line exact middle-man passthrough proxies that delegate without transformation or validation.
- **Subsystem Facade Invariant**: Primary subsystems (`src/domain/`, `src/client/store/`, `src/client/audio/`, `src/client/events/`, `src/client/network/`, `src/client/ui/`, `src/client/3d/`, `src/domain/protocol/`) MUST expose an authoritative `index.ts` public facade. External consumers MUST import exclusively via facades or path aliases, never reaching into internal leaf files (`*_helpers.ts`, `*_calc.ts`).
- **Mechanical Boundary & Protocol Seam Invariant**: Client components (`src/client/**`) MUST NEVER import directly from `src/server/**`. All shared network envelopes, player intents, and match snapshots MUST reside in `src/domain/protocol/` (or `@protocol`). Deep relative imports crossing >= 3 directory levels (`../../../../`) bypassing facades are prohibited.
- **Zero Circular Dependency Invariant**: Introducing new circular dependency loops (SCCs) across `src/**` is strictly FORBIDDEN. Enforced mechanically via `npm run lint:boundaries` and prefilter.
- **SpecGuard Oracle & Anti-Overfitting Invariant (arXiv:2610.16870)**: Test Oracles MUST remain independent from production reference code. FORBIDDEN authoring tests that mirror internal private variable names, temporary loops, or specific data structure choices instead of public behavioral specifications. Every contract test suite MUST include at least one Negative/Violation test case proving that malformed inputs, illegal state transitions, or rule breaches are actively rejected (Zero-Rejection Harness Ban). Solitary change-detection assertions (`expect(x).toBeDefined()`, `expect(x).toBeTruthy()`) without value/relational verification are banned.
- **Anti-Cheat Test Integrity Invariant**: FORBIDDEN `implementer` modifying test files via file tools or shell commands (enforced via Hook + Station 1 `testFileSha256` lock). FORBIDDEN contract tests mocking target production modules (`vi.mock`/`jest.mock` on `targetFiles`). Tests MUST verify public observable contracts, NEVER unmounted intermediate element props or private implementation details (Anti-Zombie/Anti-Tautological Tests). Obsolete tests blocking clean refactors must be modernized under plan authorization. Pure calculation tests MUST assert relational covariance across $\ge 2$ inputs ($f(x_1) \neq f(x_2)$) to defeat constant-return hardcoding.
- **Dropped Requirements & Anti-Phantom Complexity Invariant (Sean Goedecke Rule)**: Declaring **Explicitly Dropped Requirements** (what is deliberately NOT handled, what can be stale, slow, inflexible, or out-of-scope) is MANDATORY in Station 0.1 & Station 1 Plans. Subagents are strictly FORBIDDEN from introducing unrequested concurrency locks (mutexes), unrequested multi-tier caching, redundant double-checking (TOCTOU guards), or speculative wrapper layers to satisfy hypothetical edge cases not demanded by the user or domain contracts. Universal subsystem profiles:
  - *UI / Presentation*: Drop multi-window overlapping modals (single-active flow invariant); drop infinite micro-breakpoint responsive tweaks (anchor to primary viewports).
  - *Realtime / Graphics*: Drop high-frequency reactive store sync (use hysteresis/coarse intervals); drop high-end desktop passes on mobile devices.
  - *Backend / State FSM*: Drop speculative distributed concurrency (strict sequential transitions); single source of truth over optimistic divergence.
  - *Automation / Bots*: Drop 0ms instant execution (pace actions for human observability); deterministic heuristic rules over complex black-box models.
- **Active Principle Traceability Invariant (`Principles Applied`)**: Every Plan, Adversarial Challenge, QA Handoff, and Implementation Handoff MUST include a concise `Principles Applied` list (`[Principle Name] -> [Specific Choice Changed]`) selected from the Core Principles Index: *(1) View-Model Seam Extraction, (2) Equivalence-Partition Testing, (3) Relational Multi-Point Assertion, (4) Ephemeral TTL / Dead Man's Switch, (5) 100% DTO & Call-Site Wiring, (6) Poka-Yoke Domain Affordance, (7) Spatial AABB / Non-Occlusion, (8) Resource Disposal & Cache Hygiene, (9) Platform DI Isolation, (10) Dropped Requirements & Anti-Phantom Complexity (Sean Goedecke Invariant), (11) Sequential Multi-Finding Remediation, (12) STRIDE Trust Boundary Defense, (13) SpecGuard Oracle & Anti-Overfitting Protocol*.
- **Sequential Multi-Finding Remediation Protocol (Anti-Shotgun Editing)**: When resolving multiple findings from Plan Audits, Adversarial Challenges, Chaos Sentinel failures, or Station 3.2 Code Reviews, agents are STRICTLY FORBIDDEN from performing multi-file shotgun edits across unrelated issues in a single unverified diff. Remediation MUST proceed sequentially, one finding at a time: (1) Author 1 discrete boundary test asserting finding #1 (RED); (2) Implement minimal defensive fix (GREEN); (3) Confirm local test passes before moving to finding #2; (4) Run full regression passes (`npm test`, `npm run prefilter`) only after all discrete findings have passed their individual TDD cycle.
- **Remediation Attempt Budget & Escalation Guard**: Subagents (`implementer`, `re-reviewer`) are constrained to a strict budget of maximum 3 attempts per discrete finding or test failure. If an issue remains unresolved after 3 attempts, subagents MUST NOT enter infinite trial-and-error loops; halt immediately, document physical blockers, and escalate to Human Review (`CHALLENGE_ESCALATED` / `MANUAL_REVIEW_REQUIRED`).

## 3. FULL RIGOR SDLC PIPELINE (COHESIVE BATCHING)
- **Tier 1 (Fast-Track)**: < 50 LOC, visual/CSS/spacing, copy, minor isolated tweak (0 Schema, 0 FSM, 0 Net). Main Agent executes directly in 1-2 min, 0 subagents, 0 plans, 0 reports. Must pass `npm run prefilter` and unit tests.
- **Tier 1.5 (Structural & Type Refactor)**: Pure compile-time types/interfaces, optional schema fields without runtime mutation, subsystem facade re-exports (`index.ts`), import path rewiring, and `declare module` purges (0 FSM transitions, 0 Economic/Cashflow math changes). Main Agent executes directly:
  - **Exemptions**: FORBIDDEN running Chaos Sentinel (`npm run sentinel`) on pure type/barrel files. Exempt from Station 1.5 Adversarial Gate and separate QA/Implementer subagent handoffs.
  - **Required Gates**: MUST pass `tsc --noEmit` (exit 0), `npm run lint:boundaries` (0 hard violations, 0 new SCCs), `npm run prefilter`, and 100% existing regression unit tests (`npm test`). Lean summary report only.
- **Standard Feature Slice (Cohesive Batching - 50 to 250 LOC - Behavioral & Economic)**:
  - **Cohesive Batching Invariant**: Tightly coupled domain logic MUST be designed and implemented as ONE cohesive slice. Arbitrary over-slicing into multiple micro-tickets that forces repeating the full 8-station pipeline is FORBIDDEN.
  - **Station 0 (Physical Surface Area Probing & Root-Cause Gate)**:
    - Run `npm run probe:surface -- <target_files>` to extract exact physical LOC, caller count across `src/**` & `tests/**`, and scan for ambient module augmentations (`declare module`).
    - For non-deterministic visual/runtime glitches: isolate physical culprit via observability hooks (`?debug=3d`, layer toggles, console traces, `window.__vtcoon`) before drafting plan.
    - For gameplay, balance, bankruptcy, or state machine desync bugs: inspect In-Game Flight Recorder dump (`npm run analyze:log <dump.json>`) before drafting plan.
  - **Station 0.1 (Solution Exploration & Dropped Requirements Gate)**:
    - Formulate 2 contrasting approaches: Option A (KISS / Least New Structure / In-place) vs Option B (Extensible / New structure).
    - Answer 3 Trade-Off Questions: What can be slow? What can be stale? What can be inflexible?
    - Declare **Explicitly Dropped Requirements** to eliminate hypothetical edge cases and prevent AI over-engineering before drafting the plan.
    - **STRIDE Threat Check (Network, Protocol, State & Economy)**: When touching client-server boundaries, WebSocket deltas (`src/domain/protocol/`, `src/server/network/`, `src/client/network/`), bot scheduling, or transactions, evaluate 6 threats: Spoofing (actor ID forging), Tampering (client-dictated prices/rent), Repudiation (unattributed action logs), Information Disclosure (leaking opponent hidden cards/dice sequence), Denial of Service (action spam/modal cancels stalling turn coordinator), Elevation of Privilege (unauthorized intent execution).
  1. **Station 1 (Draft Lean Plan)**: `.agents/plans/PLAN_[ID].md` (<= 200 lines, 0 code-dump, Core Contract Invariants anchoring numbers/wiring, and an `Explicitly Dropped Requirements` section). For decommissioned modules/shims, apply the **Two-Stage Decoupling Pattern** (Phase 1: rewire production and retain 1-line `export * from` stub to protect living tests; Phase 2: modernize tests and delete stub).
  2. **Station 1.2 & 1.5 (Same-Turn Plan Audit & Adversarial Gate)**: Dispatch `node scripts/audit_plan.mjs <plan> --auto-sign` (enforcing mechanical surface probes: ambient module augmentation, export parity, living test callers) and 1 blind adversarial round (`adversarial-challenger` or `forensic-challenger` -> `.agents/audit/PLAN_CHALLENGE_[TICKET].md`) **in the same turn** whenever touching FSM, State, Economy, UI, Mobile, or 3D. Neutral Blind Dispatch Protocol: FORBIDDEN feeding leading hints; auditor MUST execute physical disk queries (`npm run probe:surface`, `vitest run` on living tests).
  3. **Station 1.8 (Human Gate)**: User approves ("đồng ý").
  4. **Station 2 (RED - Autonomous QA Contract Suite)**: Scaffold empty stubs in `src/**` for new files; `qa-tester` consumes the Plan's Core Invariants + Type/DTO contracts and autonomously authors atomic tests by Equivalence Partition (1 test = 1 distinct branch/facet, covering 100% of exported symbols with 0 redundant bloat, Semantic Behavioral RED).
  5. **Station 2.5 (GREEN - Implementation)**: `implementer` writes minimal code in `src/**`.
  6. **Station 3 (Mechanical Verification & Visual Capture Gate)**: Run `npm run prefilter -- <files>`, `node scripts/check_scope.mjs`, and (for UI/3D tickets) `capture_visual_evidence.mjs` while `src/**` is static (NEVER run alongside `sentinel`).
  7. **Station 3.5 (Same-Turn Chaos Sentinel & Visual Critic Gate)**: Dispatch `npm run sentinel -- --ticket <id> --test <test_path>` (exclusive `src/**` mutation lock) and (if UI/3D screenshots exist) `game-3d-visual-critic` **in the same turn**.
  8. **Station 4 (Evidence Synthesis & Delivery Reports)**: Main Agent deterministically synthesizes station audits (`.agents/audit/SPEC_REVIEW_[ID].md`, `CODE_REVIEW_[ID].md`, `PLAN_CHALLENGE_[ID].md`) and final acceptance report (`docs/reports/improvements/IMP-[ID]-[slug]_report.md`) via `npm run report -- [ID]`. Pass `node scripts/check_evidence.mjs <ticket>`. Perform 1:1 physical disk self-audit before presenting.
- **Epic / Major Multi-Subsystem (> 250 LOC, > 3-4 files across different subsystems)**:
  - Sliced only at natural architectural boundaries into cohesive feature slices. Roadmaps emit high-level milestones before planning.
