## 1. Tóm Tắt Toàn Diện Tiến Trình 4 Vertical Slices (Epic 3 Lifecycle)

```
[Browser Client A] ──WSS──┐
[Browser Client B] ──WSS──┤
[Browser Client C] ──WSS──┼──► [WssServer (Port 3001)]
[Browser Client D] ──WSS──┤         │
                          │         ▼
                          │    ┌────────────────────────┐
                          │    │      IntentMutex       │ (FIFO Queue / RoomCode)
                          │    └────────────┬───────────┘
                          │                 ▼
                          │    ┌────────────────────────┐
                          │    │    RoomManager FSM     │
                          │    └────────────┬───────────┘
                          │                 ▼
                          │    ┌────────────────────────┐
                          │    │    DeltaBroadcaster    │
                          │    │ - buildSparseDelta     │
                          │    │ - Size Guard < 10KB    │
                          │    │ - isMortgaged: false   │
                          │    └────────────┬───────────┘
                          │                 │ (Broadcast STATE_DELTA)
                          │                 ▼
                          │    ┌────────────────────────┐
                          │    │    ReconnectManager    │
                          │    │ - Reconnect Token      │
                          │    │ - Grace Period 60s     │
                          │    │ - Bot Takeover         │
                          │    └────────────────────────┘
```

## 3. Nhật Ký Lỗi Khắc Phục (Gotchas & Bug Resolution)

1. **Lỗi kẹt FSM Bot khi kết thúc ân hạn (`runBotTurn` Deadlock)**:
   - *Hiện tượng:* Khi người chơi mất kết nối quá 60s trong lượt của mình, `BotEngine.takeover` tiếp quản nhưng `runBotTurn` bị dừng ngay sau khi đổ xúc xắc do lệnh `break;`, để lại phòng đấu bị kẹt vĩnh viễn ở `TurnPhase.ActionPhase`.
   - *Khắc phục:* Chuyển vòng lặp sang tiếp tục xử lý các quyết định mua đất, đấu giá, từ chối và gọi `executeTurnEnd` cho tới khi lượt chơi chuyển giao sang người khác (`active.id !== current.id`).
2. **Lỗ hổng Zombie Socket khi kết nối lại**:
   - *Hiện tượng:* Khi người chơi reload trang hoặc mở tab mới, socket cũ chưa kịp đóng vẫn nằm trong danh sách broadcast, nhận đúp gói tin và tạo race condition.
   - *Khắc phục:* Trong `handleReconnect`, server chủ động tìm kiếm và đóng cưỡng bức socket cũ thuộc cặp `roomCode:playerId` đó với mã đóng `1000 ('SUPERSEDED_BY_RECONNECT')`.
3. **Mất cờ giải chấp trong Sparse Diff (`isMortgaged: false`)**:
   - *Hiện tượng:* Người chơi giải chấp BĐS nhưng client store không nhận được cờ `isMortgaged: false` (do domain chỉ set `isMortgaged: true` khi có thế chấp, giải chấp thì thuộc tính bị `undefined`).
   - *Khắc phục:* `buildSparseDelta` phát hiện ô trước đó có thế chấp nhưng trạng thái mới không còn thế chấp -> chủ động chèn `isMortgaged: false` vào gói vi sai để client gỡ bỏ khỏi `mortgagedProperties`.
4. **Lặp vô hạn Reconnect trong React Hook `useGameWs`**:
   - *Hiện tượng:* Callback inline đổi reference khiến `useCallback` tạo hàm mới liên tục, ngắt và mở lại socket mỗi khi store cập nhật.
   - *Khắc phục:* Đưa các callback `onDelta` và `onError` vào `useRef`.
