## 3. Kỹ Năng Đề Xuất Cho Phiên Làm Việc Kế Tiếp (Suggested Skills)

Dành cho Agent tiếp quản trong các tác vụ vận hành thực địa hoặc bảo trì định kỳ:
1. **`verification-before-completion`**: Chạy `npm test` và `npm run build` trước khi thực hiện bất kỳ lệnh deploy hoặc hotfix nào.
2. **`code-review`**: Rà soát tiêu chuẩn mã nguồn khi bổ sung tính năng kinh doanh mới.
3. **`diagnosing-bugs`**: Hỗ trợ chẩn đoán nếu phát hiện vấn đề kết nối WSS từ client đặc thù qua Nginx proxy.
4. **`systematic-debugging`**: Điều tra nguyên nhân gốc rễ nếu phát sinh ngoại lệ runtime trên máy chủ Docker.

## 4. Các Hành Động Tiếp Theo Cho Đội Ngũ Vận Hành (DevOps Next Steps)

Khi đưa hệ thống lên máy chủ VPS Linux (Ubuntu 22.04 LTS):
1. **Chuẩn bị môi trường:**
   - Cài đặt Docker & Docker Compose plugin trên máy chủ.
   - Trỏ bản ghi DNS Domain (ví dụ: `vtcoon.vn`) về địa chỉ IP máy chủ.
2. **Cấu hình biến môi trường:**
   - Tạo tệp `.env` tại thư mục gốc theo hướng dẫn tại [`docs/ops/ops_runbook.md`](file:///c:/Users/HP/Documents/GitHub/vtcoon/docs/ops/ops_runbook.md):
     ```env
     NODE_ENV=production
     WSS_PORT=3001
     GRACE_PERIOD_MS=60000
     ```
3. **Khởi chạy hệ thống:**
   - Thực thi lệnh: `docker compose up -d --build`
   - Cấp chứng chỉ Let's Encrypt chính thức:
     ```bash
     certbot certonly --webroot -w /var/www/certbot -d vtcoon.vn
     docker compose exec nginx nginx -s reload
     ```
4. **Kiểm tra giám sát:**
   - `curl -f http://127.0.0.1:3000/health`
   - `docker compose logs -f vtcoon`
